# Agent Guidelines & Rules

## Documentation Maintenance
- **Do NOT update documentation for small code changes, especially UX.**
- Do not modify `README.md`, `docs/*`, or other documentation files for:
  - Small code changes, bug fixes, or code cleanup
  - UX adjustments, styling, or CSS tweaks (colors, shapes, borders, fonts, spacing, layout alignments)
  - Small visual elements, badges, icons, or micro-copy
  - Minor UI enhancements or animations
- **Only update documentation** when:
  - Introducing major new user-facing features, new routes/pages, or new leagues
  - Modifying critical production operations, environment requirements, or deployment pipelines
  - The user explicitly asks to update the documentation
